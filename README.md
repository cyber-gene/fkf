# 自由からあげ財団

自由からあげ運動を推進する非営利団体のウェブサイト。

## 開発

```bash
npm install
npm run dev
```

`http://localhost:4321` でプレビューできます。

## ビルド

```bash
npm run build
```

`dist/` ディレクトリに静的ファイルが生成されます。

## デプロイ

Netlify にリポジトリを接続するだけで自動デプロイされます。ビルド設定は `netlify.toml` に記載済みです。

## 技術スタック

- [Astro](https://astro.build/)
- [Tailwind CSS](https://tailwindcss.com/)
- Netlify
